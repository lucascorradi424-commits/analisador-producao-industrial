# ⚙️ Simulador de Eficiência Industrial (OEE / FTY)

Interface web interativa para simulação e monitoramento em tempo real de métricas operacionais e indicadores de qualidade em linhas de produção industrial.

---

## 📌 Sobre o Projeto

Este projeto combina conceitos de **Engenharia de Produção** com **desenvolvimento web** básico para criar um painel simples, ágil e visual de acompanhamento de indicadores de desempenho.

A aplicação simula ciclos de operação de maquinário, gerando dados estocásticos de peças conformes e não conformes para cálculo instantâneo da eficiência e rendimento da linha.

---

## 🚀 Funcionalidades

- **Simulação Estocástica:** Geração dinâmica de dados de produção simulando um ambiente fabril real.
- **Cálculo de FTY (First Time Yield):** Mensuração instantânea da taxa de qualidade das peças aprovadas na primeira passagem.
- **Interface Responsiva:** Design limpo, leve e executável diretamente em qualquer navegador, sem necessidade de servidores ou instalação de dependências.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página.
- **CSS3:** Estilização de cartões (cards), botões interativos e responsividade.
- **JavaScript (Vanilla):** Lógica matemática de simulação e manipulação dinâmica do DOM.

---

## 💻 Como Executar o Projeto

### Opção 1: Direto no Computador (Sem Instalações)
1. Baixe ou clone este repositório no seu computador.
2. Dê um duplo clique no arquivo `index.html`.
3. O projeto abrirá instantaneamente no seu navegador padrão (Chrome, Edge, Firefox, etc.).

### Opção 2: No VS Code com Live Server
1. Abra o projeto no VS Code.
2. Instale a extensão **Live Server** (caso ainda não a possua).
3. Clique com o botão direito no arquivo `index.html` e selecione **Open with Live Server**.

---

## 📈 Indicadores Calculados

| Métrica | Descrição |
| :--- | :--- |
| **Peças Válidas** | Quantidade de unidades produzidas em conformidade técnica. |
| **Defeitos** | Quantidade de peças não conformes geradas no ciclo. |
| **Qualidade (FTY)** | Razão percentual de itens aprovados em relação ao total produzido no ciclo. |
